# SMAPI

### The Stardew Valley modding API

SMAPI is the modding framework that powers the entire Stardew Valley mod ecosystem. It loads mods, provides a rich API for game interaction, and ensures compatibility between the thousands of mods that use it.

<br>

---

## Features

| | |
|:---|:---|
| **Foundation for Everything** | Required by nearly every Stardew Valley mod ever made |
| **Safe Modding** | SMAPI doesn't modify game files — mods run safely in memory |
| **Update Checks** | Automatically notifies you when your installed mods have updates |
| **Console & Logging** | Built-in console and detailed logs make troubleshooting easy |
